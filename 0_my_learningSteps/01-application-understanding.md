# Application Understanding

## What we started with

We received the UI Functional E2E Test Case Catalog for HealthOps.

## What the catalog tells us

- The application is HealthOps – Healthcare Operations Management System.
- The catalog is based on the application as currently implemented.
- It covers UI functional and E2E testing.
- API-only, performance, penetration and other out-of-scope areas are excluded.
- The catalog is the source for later automation authoring.
